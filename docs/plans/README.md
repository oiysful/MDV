## [`20-copy-clipboard-flake-and-doc-reconciliation.md`](./done/2026-09-21/20-copy-clipboard-flake-and-doc-reconciliation.md) — 복사 테스트 플레이크 + 플레이크 목록 문서 정합 (2026-09-18 계획, 2026-09-21 수정)

**A**: `boot-and-render.test.js`의 복사 테스트가 병렬 실행에서 간헐적으로 15초 타임아웃을 냈다. **계획서가 세운 유력 가설은 실측으로 기각됐다** — Playwright 하의 Electron에서는 `blur()`/`minimize()`/`hide()` 어느 것도 `document.hasFocus()`를 뒤집지 못하고 클립보드 쓰기는 전부 성공하므로, "포커스 없는 문서라 클립보드가 거부된다"는 이야기는 이 하네스에서 성립할 수 없다. 보안 문서 2종이 상속해 온 "OS 포커스 경합" 설명도 같이 무너졌다. 실제 원인은 계획 18이 `#toast`에서 이미 한 번 고친 것과 같은 계열 — **`.copied`는 상태가 아니라 1.5초짜리 창**이고(실측: 22ms에 붙어 1524ms에 사라짐), 클래스·체크 아이콘·숨은 툴팁 세 단언이 그 하나의 만료되는 조건에 사슬로 얹혀 있었다. 실패 시 토스트 기록은 `코드 복사됨`이다 — 복사가 아니라 관측이 늦은 것이다. 수정은 계획 19의 게이트: 복원 타이머를 테스트가 붙잡고 풀 시점을 정하며, 그 덕에 복원 자체를 처음으로 단언하게 됐다. 대기를 5초 굶겨도 통과하고(예전 코드는 1.7초에 죽는다), 상수 드리프트를 심으면 명시적으로 실패한다. **B**: 같은 플레이크 목록을 `AGENTS.md`와 보안 문서 2종이 각자 적고 있어 교집합이 한 건뿐이었고, 그 갈라짐 때문에 A가 세 번의 수정 내내 시야 밖에 있었다. 다섯 행을 전부 실물 대조했더니 **계획서 자신의 표도 이미 낡아 있었다**(`792ece1`이 네 번째 행을 이미 추가한 뒤였다). 정본을 `AGENTS.md`로 모으고, 보안 문서는 게이트 신뢰 논지만 남긴 채 참조하게 했다.
