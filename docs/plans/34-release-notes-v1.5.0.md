## MDV v1.5.0

> **Full Changelog**: https://github.com/oiysful/MDV/compare/v1.4.0...v1.5.0

> [!NOTE]
> **문서에 직접 쓴 HTML의 `class`와 inline `style`은 이제 적용되지 않습니다.** 보안 수정 때문입니다(아래 🔐). 이미지의 `width`·`height`와 `align` 같은 표시용 속성은 그대로 적용됩니다.

### ⬆️ Upgrade
```shell
# Homebrew 사용을 권장합니다!
brew upgrade --cask oiysful/tap/mdv
```

### ✨ 새 기능
- **영어 인터페이스**: 메뉴, 버튼, 안내, 대화상자가 macOS 언어 설정을 따라 한국어나 영어로 나옵니다. 앱별 언어 설정(시스템 설정 → 일반 → 언어 및 지역 → 앱)으로 MDV만 바꿀 수도 있습니다. 한국어·영어가 아닌 언어에서는 영어로 나옵니다.

### 🔧 개선
- **분할 보기를 오가도 읽던 위치 유지**: 분할 보기에 들어가거나 나올 때, 그리고 분할 보기에서 ⌘U로 나갈 때 보던 곳에 머뭅니다.
- **Markdown 해석 엔진 업그레이드(marked 9 → 18)**: CommonMark 규칙을 더 정확히 따릅니다. 예를 들어 문단 바로 다음 줄에 오는 코드 펜스를 이제 코드 블록으로 인식합니다. 전에는 그 뒤의 `---`가 제목으로 바뀌기도 했습니다.
- **다이어그램 엔진 업그레이드(mermaid 11 → 12)**: 플로차트 같은 다이어그램이 새 배치 엔진(ELK)과 새 외관으로 그려집니다. 기존 다이어그램의 모양과 크기가 달라질 수 있습니다.
- 런타임 업그레이드: **Electron 44.10.2**, marked 18.2.0, mermaid 12.3.0, DOMPurify 3.4.17

### 🐛 버그 수정
- 목차 강조가 실제 읽는 위치와 어긋나던 문제를 고쳤습니다. 문서를 다시 그린 뒤나 탭을 복원한 뒤에 생겼습니다.
- 메뉴에서 앱 이름이 소문자 `mdv`로 나오던 문제를 고쳤습니다.
- `**Exit <= 20%** (…)`처럼 기호로 끝나는 굵게 뒤에 공백이 오는 경우 굵게가 되지 않던 문제를 고쳤습니다.

### 🔐 보안
- 보안 감사 **96/100** (2026-11-10). critical·high·medium·low 0건
- **위조된 복사 버튼 차단**: 문서의 HTML이 MDV의 코드 복사 버튼을 그대로 흉내 내어, 화면에 보이지 않는 텍스트를 복사하게 만들 수 있었습니다. 이제 MDV가 직접 만든 버튼만 동작합니다. 또 문서 HTML이 `class`·`style`로 코드 블록 일부를 가릴 수 없도록 두 속성을 지웁니다.
- **앱을 Node로 실행하는 경로 차단**: 배포된 앱을 `ELECTRON_RUN_AS_NODE`·`NODE_OPTIONS`·`--inspect`로 임의 스크립트 실행기로 쓸 수 있었습니다. 해당 Electron fuse 세 개를 끄고 앱을 다시 서명합니다.
- **악의적인 문서로 렌더러가 멈추던 문제 완화**: 짝이 맞지 않는 `*`·`_`를 많이 넣은 문서는 64KB만으로도 렌더러를 30초 넘게 멈출 수 있었습니다(marked #4099). 이제 즉시 렌더링됩니다. 아주 큰 인용문 하나로 느려지는 경우는 남아 있습니다(알려진 제한사항).
- 보안 패치: DOMPurify 3.4.17(critical 권고 3건), Electron 44.10.2(Chromium·V8 보안 백포트), mermaid 내장 DOMPurify·KaTeX 갱신

### ⚠️ 알려진 제한사항
marked 18로 바뀌며 생긴 차이입니다. 자세한 내용은 [README](https://github.com/oiysful/MDV#known-limitations)를 보세요.
- 기호나 이모지로 끝나는 굵게·기울임 바로 뒤에 글자가 붙으면(예: `**완료 ✅**다`) 강조가 되지 않습니다. github.com에서는 강조가 됩니다. 기호를 별표 밖으로 빼면(`**완료**✅다`) 됩니다.
- `<Agent_Prompt>`처럼 밑줄이 든 태그 모양 텍스트는 이제 글자 그대로 보입니다. 전에는 사라졌고, 지금 동작이 github.com과 같습니다.
